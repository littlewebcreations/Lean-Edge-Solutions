# Lean Edge Solutions website

## Overview
Build a polished, multi-page consultancy website from the supplied business overview. The visual language will adapt Martin’s Mission’s strong typography, high contrast, generous spacing, direct calls to action, and numbered content blocks, while using Lean Edge Solutions’ own green, cyan, charcoal, and white branding.

## Pages
- **Home** — brand-led opening with the core promise, industrial photography, key outcomes, a concise services overview, the five-step working method, and a clear enquiry prompt.
- **Services** — two clearly structured service areas: Operational Excellence and Leadership & Performance, including all capabilities from the supplied document.
- **EDGE 360** — dedicated assessment page covering its purpose, the eight performance areas, expected outcomes, and a focused enquiry action.
- **About** — who Lean Edge Solutions is, its practical approach, typical engagements, ideal clients, and the Practical / Measurable / Sustainable values.
- **Contact** — accessible enquiry form sending submissions to `sales@leanedge.co.uk`, with validation, success, loading, and error feedback.

## Shared experience
- Create a responsive header with the supplied Lean Edge Solutions logo, desktop navigation, compact mobile menu, and a prominent contact action.
- Create a restrained footer with essential navigation, the business email, and brand statement.
- Use Montserrat-style geometric headings and Source Sans Pro-style body copy to reflect the reference site.
- Use the company’s bright green and cyan as purposeful accents against white, charcoal, and light neutral sections.
- Generate cohesive, authentic industrial photography showing real manufacturing environments, operational observation, and leadership collaboration.
- Keep motion subtle: navigation transitions, restrained image reveals, and purposeful interaction feedback, with reduced-motion support.

## Content and presentation
- Preserve the supplied wording while correcting obvious presentation errors, including consistently using “Lean Edge Solutions” and “Operational Excellence.”
- Turn dense lists into readable grouped sections without losing any supplied services or outcomes.
- Use numbered layouts for the five-step process, echoing the reference site’s numbered aims pattern.
- Ensure one clear heading per page, descriptive image text, strong contrast, keyboard-friendly controls, and layouts that work across mobile and desktop.

## Technical details
- Add separate routes for Home, Services, EDGE 360, About, and Contact, each with unique search and social metadata.
- Build reusable site header, footer, page introduction, call-to-action, outcome, and numbered-process elements.
- Define all brand colours, typography, spacing, radii, and interaction states as shared design tokens.
- Use the uploaded logo extracted from the supplied PDF as a site asset.
- Enable Lovable Cloud for secure contact-form handling and deliver enquiries to `sales@leanedge.co.uk`; email delivery configuration may require the relevant sending-service credential.
- Validate page rendering, navigation, mobile layouts, form states, accessibility basics, and browser console health before completion.
